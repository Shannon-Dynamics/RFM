## What is in this folder

- `references.csv`: one row per reference (title, authors, date, arXiv ID and version, URL, local files, where Book.md cites it, the tag Book.md gives it, notes). It can seed the appendix A catalog and the appendix F claim register.
- `references.bib`: a BibTeX entry for every reference, for appendix D.
- `01-...` to `11-...`: the documents. Folders 01 to 05 follow Book.md section 5; folders 06 to 10 hold works that the chapters name but section 5 does not list; folder 11 holds the industry and practitioner sources.
- arXiv papers are saved as `<key>_<arXiv id>.pdf` (latest version; the version is listed below). Web pages are saved twice: `<key>.pdf` is the page as rendered, `<key>.md` is its main text with the source URL and dates at the top (`<key>__<label>.*` when a reference has several web sources). GitHub sources are saved as their README (`.md`).

## Findings that affect Book.md

### 1. JEPA-WAM: the arXiv ID in Book.md probably points to the wrong paper

Book.md cites JEPA-WAM as arXiv 2609.20277 and uses it as a latent-prediction world-action model (chapter 7; chapter 18: "representation prediction instead of pixel prediction"). Two different papers carry that name:

- **2609.20277** (Liu et al.; v1 dated 4 August 2026, with a September 2026 arXiv number) adds generated visual instructions to text instructions to improve instruction following. The JEPA latents connect those images to the WAM.
- **2608.09381** (Lin et al., August 2026) is a latent WAM built in V-JEPA space that predicts current and future latents instead of generating video. This is the JEPA-WAM the WAM survey cites (its reference [112]), and it matches Book.md's description.

Both are saved in `04-latent-prediction-and-latent-actions/`.

### 2. GigaWorld-Policy is two papers

Chapter 6 (the 2x2 table) and chapter 18 name "GigaWorld-Policy". Book.md gives an ID only for GigaWorld-Policy-0.5 (2607.13960, July 2026). The original GigaWorld-Policy is 2603.17240 (March 2026), which the WAM survey cites as [25]. Both are saved.

- **Journal versions:** Psiris et al. (2604.15395) is now published in TMLR (July 2026), per its arXiv journal reference. The TRI LBM paper (2507.05331) is published in Science Robotics 11(113), 2026, per the WAM survey.

These include DreamZero (17 February 2026), Cosmos Policy (22 January 2026), Fast-WAM (17 March 2026), MEM (4 March 2026), PhysWorld (10 November 2025), the WAM survey (13 September 2026) and Li et al. v7 (8 November 2025). The dates for GR00T N2 (16 March 2026), GEN-0 (4 November 2025), GEN-1 (2 April 2026) and ER 2 (30 July 2026) also match the pages.
- **Papers published under a different title** from the name Book.md uses: LingBot-VLA 2.0, LingBot-VA, Seer, VLA-MBPO, Cloth-WM, IWS and InternVLA-N1. See the table below.
- **GR00T N2 and DreamZero:** NVIDIA's GTC newsroom post (16 March 2026) describes GR00T N2 as "based on DreamZero" research. This bears on where chapter 6 places it.
- **SONIC:** the Isaac-GR00T README names the GEAR-SONIC controller for N1.7 whole-body control, which is the SONIC paper saved here (2511.07820).
- **Sources with no paper:** Cosmos-Reason2 has no paper, so its model card and repository README are saved with the Cosmos-Reason1 paper. Veo has no architecture paper, so the DeepMind model page and the Veo 3 study "Video models are zero-shot learners and reasoners" are saved.
